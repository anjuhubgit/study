3. Verify your nginx.conf
You added the COPY nginx.conf line. If that file is misconfigured, Nginx might be looking in the wrong place. Ensure your local nginx.conf looks exactly like this:

Nginx

server {
    listen 80;
    server_name localhost;

    location / {
        root   /usr/share/nginx/html;
        index  index.html index.htm;
        try_files $uri $uri/ /index.html;
    }
}

1. The Essential Change
In your package.json, find this line: "homepage": "https://aditya-sridhar.github.io/simple-reactjs-app",

Change it to: "homepage": ".",

Why is this necessary?
When you use a specific URL in the homepage field, react-scripts build assumes the application is being hosted in a sub-folder (in your case, a folder named /simple-reactjs-app/).

Because of this, the generated index.html tries to load your JavaScript and CSS files from: http://<your-ip>/simple-reactjs-app/static/js/main.js

However, in your Nginx Docker container, those files are actually located at: http://<your-ip>/static/js/main.js

By setting "homepage": ".", you tell React to use relative paths. This allows the app to find its files regardless of whether it's on GitHub Pages or your EC2 Public IP.

3. Next Steps to Deploy
After saving the change to package.json, you must rebuild your Docker image because the "build" happens during the image creation phase.

Run these commands on your Amazon Linux instance:

Rebuild the image: docker build -t simple-react-app .

Stop the old container: docker stop <container_id>

Run the new container: docker run -d -p 80:80 simple-react-app
